## О проекте

**NextTier** — платформа для игроков в CS2, которая упрощает поиск партнёров по команде, благодаря маркету игроков, организовывает тренировочные матчи и помогает в формировании киберспортивных команд. Пользователь авторизуется через Faceit, создаёт профиль и может искать подходящих игроков через market, фильтровать и сравнивать их по игровым параметрам и связываться через Telegram.

Реализовано в MVP 1.0.0

* **Авторизация через Faceit** — OAuth-авторизация, создание локального профиля при первом входе и определение дальнейшего маршрута пользователя.
* **Onboarding** — заполнение профиля: игровая роль, возраст, Telegram, prime time и цель поиска.
* **Профиль игрока** — просмотр и редактирование основных данных профиля, включая Telegram, игровую роль, prime time и аватар.
* **Market игроков** — просмотр игроков, фильтрация, сортировка и пагинация по игровым параметрам: ELO, роль, количество матчей, K/D, возраст и prime time.
* **Оценка совместимости игроков** — расчёт процента совпадения по набору игровых и пользовательских параметров.
* **Обратная связь** — отправка обращений типа Bug / Wish / Suggestion с возможностью прикрепить до 3 файлов.
* **Административная панель** — Dashboard с KPI, раздел Users со списком и фильтрацией пользователей и раздел Feedback для просмотра и обработки обращений.
* **Синхронизация данных Faceit** — фоновое обновление профилей, статистики и последних матчей пользователей с учётом ограничений внешнего API.
* **Продуктовые события** — журнал действий пользователей для последующего анализа и отображения статистики в административной панели.


В будущем планируется добавление других игр и нового функционала.

Проект разрабатывается командой из 6 человек: 1 backend разработчик, 1 frontend разработчик, 1 дизайнер, 3 системных аналитика.
